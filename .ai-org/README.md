# AI Org Studio adapter

Studio consumes the existing AppsWorld AI Organization.

## Safety

- Background execution remains disabled until validated.
- No paid engine fallback.
- No automatic merging or production deployment.
- Never expose credentials or private founder context.
- Preserve independent QA and reviewed handovers.
- Do not modify Parent Plus while developing Studio.

## Integration requirements

- Founder instruction to durable task.
- Task to existing AI Org worker.
- Enforced model and cost policy.
- Independent QA and execution evidence.
- Founder feedback and correction workflow.

The manifest declares intended policy. Runtime enforcement
must be implemented and tested before enabling execution.
